### 4. Sửa 5 Lỗi Chat

#### Lỗi 1: Conversation không hiển thị
- **Vấn đề:** Backend trả về `{ items }`, frontend expect `{ data }`
- **Giải pháp:** Map response đúng format

#### Lỗi 2: Không gửi được tin nhắn
- **Vấn đề:** Backend expect `body`, frontend gửi `text`
- **Giải pháp:** Đổi field name

#### Lỗi 3: Tin nhắn không hiển thị sau khi gửi
- **Vấn đề:** Chỉ dựa vào Socket.IO
- **Giải pháp:** Thêm message vào state ngay lập tức

#### Lỗi 4: Messages không load
- **Vấn đề:** Backend trả về `{ items }`, frontend expect `{ data }`
- **Giải pháp:** Map response đúng format

#### Lỗi 5: Field mismatch
- **Vấn đề:** Backend có `id` và `body`, frontend expect `_id` và `text`
- **Giải pháp:** Map khi load messages

**Files thay đổi:**
- `fe/src/services/chatService.ts`
- `fe/src/pages/Chat.tsx`
